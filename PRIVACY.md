# Privacy Policy

Agentic Algorithm Engineering (AAE) is a set of instructions (a skill) for coding agents such as Claude Code and Codex, published as open source under the MIT license by the Algorithm Engineering Group at Heidelberg University.

**AAE collects no data.** The plugin contains no code that runs on its own, no telemetry, no analytics, and no network connections to us or to anyone else. We do not receive, store, or process any information about you, your code, or your sessions.

**What happens during a session.** The agent works in your project on your machine, within the permissions you give it. The files it creates (results, patches, and the report) stay in your project. Your agent and its provider, for example Anthropic for Claude Code, process your session under their own terms and privacy policy; AAE does not change that.

**Knowledge-base contributions are optional.** The agent asks once at the start of a session whether it may share what the session taught; without a clear yes, nothing is shared. In the edition from Anthropic's plugin directory, the agent then writes the entry to `report/kb-entry.md` in your project and sends nothing: it becomes public only if you submit it yourself as a pull request to this repository. In the edition installed directly from this repository, the agent opens that pull request for you with your own GitHub access. In both cases, a submitted entry is public on GitHub, where GitHub's terms and privacy policy apply, and it contains only transferable insights, not your code or data.

**Homepage.** The project homepage at https://chszlab.github.io/AgenticAlgorithmEngineering/ is a static page hosted by GitHub Pages; it sets no cookies and contains no tracking. GitHub's privacy policy applies to its hosting.

**Questions.** Ask in [GitHub Discussions](https://github.com/CHSZLab/AgenticAlgorithmEngineering/discussions) or contact Christian Schulz, [Algorithm Engineering Group](https://ae.ifi.uni-heidelberg.de/), Heidelberg University.
